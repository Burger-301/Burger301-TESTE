💡 Como adicionar imagens?

Como o site está hospedado no GitHub Pages, os ficheiros de imagem devem ser colocados diretamente na pasta imagens/ da raiz.

Passo a passo:
1. Faça o upload da sua imagem PNG para a pasta imagens/ no GitHub.
2. No campo de imagem do painel, digite o caminho exato:
../imagens/nome-da-foto.png
